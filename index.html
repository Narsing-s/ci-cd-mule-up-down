Configure MuleSoft credentials

These are not entered into the UI. Add them as Environment secrets in GitHub.

ANYPOINT_CLIENT_IDConnected App client ID
ANYPOINT_CLIENT_SECRETConnected App client secret
ANYPOINT_ORG_IDAnypoint Organization ID

For example: GitHub → Settings → Environments → prod → Environment secrets. Repeat for dev/qa/sandbox/design when required. The selected GitHub Environment is the source of truth.

Selected environment: dev. Make sure its three secrets are configured before running.

What errors mean

GitHub 401/403 = token or repository permission problem. Workflow dispatch 404 = repository/workflow/ref problem. Anypoint authentication failed = Client ID/Secret or Connected App authorization problem. Environment not found = the Anypoint environment name does not match DEV/QA/SANDBOX/DESIGN/PROD.
