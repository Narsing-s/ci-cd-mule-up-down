# Security Policy

## Credentials

This project uses a bring-your-own-credentials model.

Do not open an issue, pull request, discussion, or commit containing:

- Anypoint client secrets
- Access tokens
- Passwords
- API keys
- GitHub personal access tokens
- Other private credentials

Store MuleSoft credentials only in the GitHub Environment secrets of your own repository.

## Reporting a security issue

Please do not publicly disclose credentials or other sensitive information.

For a security issue in the project, contact the repository maintainer privately through the contact options available on the maintainer's GitHub profile.

## Production protection

For production use, protect the `prod` GitHub Environment with required reviewers and restrict repository write permissions.
